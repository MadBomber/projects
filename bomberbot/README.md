# bomberbot state

- `taste.md`: rules learned from what Dewayne merges, rejects, and comments on.
- `runs.md`: one dated entry per run, newest first.
- `findings/<repo>.md`: running backlog of audit findings per repo, with status.
- `plans/`: longer audit write-ups that a finding points to.

The prompt that drives this lives in `~/.prompts/bomberbot.md`.
